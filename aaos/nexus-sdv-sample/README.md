# nexus-sdv-sample

Sample AAOS SDV service bundles that interact with their cloud counterparts in Nexus SDV, in the APEX `com.nexussdv.sample`.

| Bundle | Topic | Message | Log line |
|---|---|---|---|
| `PressureAdvisor` | `pressure-limit` | `PressureLimit` | `pressure-advisor: max_pressure=<n>` |
| `DoorController` | `door-command` | `DoorCommand` (`LOCK`, `UNLOCK`) | `door-controller: action=<LOCK\|UNLOCK>` |

## Files

| Directory | Contents |
|---|---|
| `catalog/` | the VSIDL catalog: `nexus_sample.proto`, `nexus_sample.vsidl` |
| `generated_rs/`, `configs/`, `apex/` | generated by `vsidlc` from the catalog |
| `services/*/src/main.rs` | generated once, with the TODO in each handler filled |

Regenerate after a catalog change: [`../vsidl-generate.sh`](../vsidl-generate.sh) `<aosp-root>`.

## Build and see it work

```bash
m com.nexussdv.sample
adb logcat -d | grep -E 'pressure-advisor|door-controller'
```
