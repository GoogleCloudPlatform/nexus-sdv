# google-quickstart

Google's quickstart `Manager`, publishing the tyre pressure for the samples.

`Manager/src/main.rs` is Google's file with its one TODO filled: a pressure falling from 240 to 200 in steps of 5, repeating.

```bash
./stage.sh <aosp-root>     # copies it into Google's quickstart; the original stays as main.rs.google
```

It reaches the vehicle with the image, as part of Google's quickstart.
